# Your animations, on a timeline

Loupe turns fire-and-forget React animations into something you can scrub like a
video — pause on any frame, mark what's off, and hand the finished motion to your
coding agent or straight to production.

<LoupeDemo />

That card above is not a video and not a mockup. It's a real Loupe scene running on a
real timeline — the same clock the tool drives. Drag the scrubber; pause anywhere.

## Why timeline-first

Every animation is a function of time. Loupe owns the time, so scrubbing back is just
setting the clock to zero and pausing is just freezing it. No state machines, no
mount-cycle guesswork — one number going up.
